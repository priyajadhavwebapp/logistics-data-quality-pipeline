This Week 2 report presents a complete data collection, cleaning, and preprocessing workflow for logistics analysis using Python. The project simulates a practical shipment dataset containing shipment IDs, order dates, origin and destination locations, transport modes, carriers, distances, shipment weights, shipment volumes, promised delivery times, actual delivery times, transportation costs, and delivery status. The raw dataset intentionally contains common data-quality problems such as missing numeric values, inconsistent category labels, duplicate shipment records, invalid negative distance values, and extreme outliers. These issues are identified through data profiling, missing-value checks, duplicate checks, descriptive statistics, and validation rules.

The preprocessing pipeline is implemented with Python and pandas. Dates and categorical fields are standardized, duplicate shipment IDs are removed, invalid distance values are converted to missing values, and missing numerical fields are imputed using the median to reduce the influence of extreme observations. Categorical missing values are handled using the mode. Outliers are detected using the Interquartile Range (IQR) method and capped at statistically reasonable lower and upper boundaries rather than deleting complete shipment records. Min-Max normalization is then applied to selected numerical variables so that features with different scales can be compared more effectively in later analytical or machine-learning workflows.

The report explains the reasoning behind every technique, includes Python code snippets, validates the cleaned dataset, and discusses how data quality affects logistics KPIs and decision-making. The final cleaned dataset is supplied with the report, together with a reusable Python script. This project demonstrates a structured and reproducible foundation for future logistics analytics, visualization, predictive modeling, delay analysis, and transportation resource optimization.
